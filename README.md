
# Microsoft Intune Homelab

A hands-on Microsoft Intune home lab designed to develop practical endpoint management skills using Microsoft Intune and Microsoft 365.

This repository documents my hands-on journey from initial tenant preparation through to enterprise-style device management, compliance, application deployment, endpoint security and troubleshooting. Every project is performed in a realistic lab environment and documented with implementation steps, screenshots, lessons learned and interview preparation notes.

---

## 🎯 Objectives

This homelab has been created to:

- Develop practical Microsoft Intune administration skills through hands-on implementation projects
- Build experience with enterprise endpoint management
- Learn modern Windows and mobile device management
- Integrate Microsoft Intune with Microsoft Entra ID and Microsoft 365
- Build a professional GitHub portfolio demonstrating enterprise-style implementation experience
- Create reusable documentation and operational procedures
- Prepare for Systems Administrator, Microsoft 365 Administrator and Endpoint Administrator roles

## 🧪 Lab Environment

The lab is based on a fictional healthcare organisation called **Bright Horizons Health**.

Current environment includes:

- Microsoft Entra ID tenant
- Microsoft Intune
- Microsoft 365
- Windows 11 virtual machines
- Proxmox Virtual Environment
- Physical Windows devices
- Android devices
- Enterprise-style users and security groups

The environment is designed to simulate a small-to-medium business with realistic administrative and operational requirements.
